Website profil pribadi sederhana yang dibuat menggunakan **HTML** dan **CSS** sebagai tugas praktikum Pemrograman Web. Website ini berisi halaman beranda, profil tentang saya, dan formulir kontak.

## 📌 Fitur

- **Home** — halaman utama dengan layout sederhana.
- **About** — menampilkan informasi profil, program studi, universitas, keahlian yang sedang dipelajari, dan portofolio.
- **Contact** — menampilkan formulir untuk memasukkan nama, email, dan pesan.
- **Navigasi** — tautan untuk berpindah antarhalaman.
- **Styling CSS** — menggunakan font Open Sans, warna, layout, panel hero, widget, dan footer.

## 🗂️ Struktur File

```text
.
├── home.html
├── about.html
├── contact.html
└── style.css
```

## 🛠️ Teknologi

- HTML5
- CSS3
- Google Fonts (Open Sans dan Open Sans Condensed)

## 🚀 Cara Menjalankan

1. Simpan seluruh file (`home.html`, `about.html`, `contact.html`, dan `style.css`) dalam satu folder.
2. Buka folder tersebut menggunakan Visual Studio Code atau editor kode lainnya.
3. Jalankan `home.html` di browser, atau gunakan ekstensi **Live Server** di Visual Studio Code.
4. Gunakan menu navigasi untuk membuka halaman lainnya.

## 📝 Catatan

Pastikan nama file dan tautan navigasi sesuai. Pada file HTML yang tersedia, beberapa tautan menggunakan `kontak.html`, sedangkan file yang diunggah bernama `contact.html`. Agar menu Contact berfungsi, samakan nama file pada tautan dengan nama file yang digunakan. Selain itu, halaman `home.html` berisi beberapa bagian layout yang perlu diperiksa kembali agar seluruh elemen berada di dalam struktur `<body>` dan `<div id="container">` dengan benar.
